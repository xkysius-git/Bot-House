# 홀로그램 UI 조작표 (TASKS #25 초안)

본체 버튼은 3개뿐이에요: **←**, **✓**, **→**. 키보드로도 똑같이 쓸 수 있어요.

| 버튼 | 키보드 |
|---|---|
| ← / → | ArrowLeft / ArrowRight |
| ✓ (짧게) | Enter |
| ✓ (0.6초 이상 길게) = 뒤로 | Escape |
| (덤) 화면 위아래 넘기기 | ArrowUp / ArrowDown, 마우스 휠 |

## 초점: 탭 줄 ↔ 화면 안

- 앱을 켜면 초점은 **상단 탭 줄**에 있어요 (선택된 탭이 깜빡여요).
- 탭 줄에서 **✓** 를 누르면 그 화면 **안으로** 들어가요.
- 화면 안에서 **✓ 길게** 를 누르면 열린 창을 하나씩 닫고, 더 닫을 게 없으면 **탭 줄로** 돌아가요.
- 마우스로 탭을 누르면 그 화면 안으로 바로 들어가요.

## 상황별 동작

| 어디 | ← / → | ✓ (짧게) | ✓ (길게) |
|---|---|---|---|
| 탭 줄 | ROOM · CHARACTERS · USAGE · SETTINGS 사이 이동 | 그 화면 안으로 | (그대로) |
| ROOM (집) | 봇 선택 바꾸기 (상태 칩·말풍선 강조) | 선택한 봇 상태 팝오버 열기 | 팝오버 닫기 → 탭 줄 |
| CHARACTERS (다마고치) | 캐릭터 바꾸기 | 돌보기 메뉴 열기 | 탭 줄 |
| CHARACTERS · 돌보기 메뉴 | 쓰다듬기 · 간식 · 응원하기 · 재우기 고르기 | 고른 행동 실행 | 메뉴 닫기 |
| USAGE (사용량) | 한 화면씩 위/아래로 넘기기 | 사용량 새로고침 | 탭 줄 |
| SETTINGS (기기 메뉴) | 재연결 · 로그 보기 · 설정 · 업데이트 확인 고르기 | 고른 항목 누르기 | 설정 창 → 로그 → 탭 줄 순서로 닫기 |

## 메모

- 앱 종료·트레이로 숨기기는 실수로 누르지 않게 3버튼 이동 목록에서 뺐어요. 본체 오른쪽 위 `–` `×` 버튼이나 SETTINGS 화면 맨 아래 링크로만 해요.
- 낮/밤 스위치는 본체 왼쪽 위에 있어요.
- 홀로그램 효과(청록빛, 흐르는 밝은 띠, 주사선, 깜빡임, 가로로 어긋나는 글리치)는 캐릭터 홀로그램(`renderer/house.js` drawHologram)과 같은 표현을 화면 전체에 씌운 거예요.
