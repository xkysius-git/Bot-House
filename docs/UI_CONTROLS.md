# 홀로그램 UI 조작표

**홀로그램은 보기 전용이에요.** 클릭·터치·휠을 받지 않고, 조작은 전부 기기 버튼으로 해요 (장현님 11-27).

## 기기 버튼

| 버튼 | 하는 일 | 키보드 |
|---|---|---|
| ◀ ▶ 윗쪽 | 화면(탭) 바꾸기: ROOM · MONS · USAGE · SETUP | – |
| ◀ ▶ 아랫쪽 | 화면 안에서 고르기 | ArrowLeft / ArrowRight |
| ◀ ▶ 아랫쪽 길게 (0.55초) | MONS에서 캐릭터 바꾸기 | ArrowUp / ArrowDown (MONS) |
| ✓ | 실행 | Enter |
| ✓ 길게 (0.6초) · 오른쪽 아래 그립 | 뒤로 (열린 창 닫기 → ROOM) | Escape |

## 화면별

| 화면 | 아래 ◀ ▶ | ✓ | 뒤로 |
|---|---|---|---|
| ROOM | 방 옮기기 (침실 · 거실 · 작업실) | 그 방 캐릭터 상태 카드 열기/닫기 | 카드 닫기 |
| MONS | 하단 감정 바에서 고르기 (쓰다듬기 · 간식 · 응원 · 재우기 · 하트 · 노래 · 반짝 · 놀람) | 고른 감정 바로 실행 | ROOM |
| USAGE | 봇 카드 넘기기 | 새로고침 | ROOM |
| SETUP | 재연결 · 로그 보기 · 설정 · 업데이트 확인 고르기 | 고른 항목 실행 | ROOM |
| 설정 창 | 항목 이동 | 체크 켜기/끄기 · 버튼 누르기 · 글자칸은 키보드 입력 시작 (Enter/Esc로 끝) | 창 닫기 |

## 메모

- 설정 창·캐릭터 상태 카드도 홀로그램 화면 안에 떠요 (따로 뜨는 창 없음).
- ROOM은 방 하나 + 양옆 반 칸이 보이게 줄였고, 캐릭터는 작게. MONS는 캐릭터가 주인공이라 크게.
- 앱 종료·트레이 숨기기는 본체 오른쪽 위 `–` `×` 로만.
