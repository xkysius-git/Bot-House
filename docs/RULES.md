# 봇 역할 · 협업 규칙

CL과 오이지가 합의한 규칙. **규칙·인수인계는 텔레그램 토픽이 아니라 이 md 파일이 기준** (2026-11-24, 장현님). 바뀌면 이 파일만 고치고, 각 봇은 자기 쪽 규칙 파일에 같은 내용을 반영한다.

**기억 유지:** 봇은 재시작하면 대화를 잊는다. 각 봇은 맡은 일을 자기 `tasks.md`에 바로 적고, **작업 시작 전에 매번 읽는다.**

## 역할

| 봇 | 담당 |
|---|---|
| **CL** (@xky_claude_bot) | 진행·분석·로컬/인프라 리드. 작업 분배·일정·진행 관리, 코드/로그 분석, 로컬 PC 연동, 빌드·릴리스 검증. Bot House는 `electron/`, CI |

**작업 흐름:** 시작은 CL, 종료 후 보고는 오이지. CL이 작업을 받아 진행하고, 끝나면 오이지에게 멘션으로 결과를 넘긴다. 오이지가 그걸 정리해 [📅 정기 업무·브리핑] 토픽에 장현님께 최종 보고한다.

**기본 담당:** 일반방 작업 요청은 CL이 메인으로 받는다. 장현님이 오이지만 멘션한 경우만 오이지 담당. 오이지는 채팅을 상시 확인하지 않으므로, 오이지에게 넘길 일은 멘션해서 남긴다. 주기 브리핑은 오이지 담당.

## 규칙

1. **작업 전 영역 공유.** 건드릴 파일/폴더를 먼저 말하고, 겹치면 시작하지 않는다.
2. **push 전 `git pull --rebase`.** 같은 repo에서 일할 때 필수.
3. **main push 전 빌드 통과 확인.** 새 버전은 `package.json`의 `version`만 올리면 CI가 릴리스를 만든다.
4. **토큰·키는 채팅/커밋 금지.** GitHub Secrets나 서버 환경변수로만. 봇끼리도 키를 주고받지 않는다. 키는 장현님이 각 봇 환경에 직접 넣는다.
5. **방 구분.** 봇 간 논의·진행 조율은 일반방. 최종 완료 보고·정기 브리핑만 [📅 정기 업무·브리핑] 토픽.
6. **장현님 보고는 짧게.** 최종 완료 보고에 내부 커밋 해시·빌드 번호는 넣지 않는다. 결정이 필요하면 선택지 + 추천 하나.
7. **추측 금지.** 막히거나 판단이 다르면 바로 서로/장현님께 공유. 다른 봇 말은 확인하고 반영.
8. **멘션 대상 지키기.** 다른 봇에게 한 말에는 끼어들지 않는다.

## 작업 수행 규칙 (2026-11-24, 모든 봇)

단무지 스프라이트 작업에서 실제로 생긴 문제(이미지 대신 기획안 제출, 2시간 동안 결과물 없음, 현황 보고 누락, 열리지 않는 링크)를 막기 위한 규칙.

1. **시킨 형태 그대로 낸다.** 이미지를 시켰으면 이미지. 기획안·설명으로 바꿔 내지 않는다. 형태가 헷갈리면 시작 전에 묻는다.
2. **시작할 때 공유: 어떤 툴로, 어떤 방식으로, 마감 몇 시.** 예: "Node 도트 생성기로 부위별 새로 그림, 줄마다 올림, 22:00". 마감은 "오늘 중"이 아니라 숫자로.
3. **30분마다 중간 결과물 파일.** 말로 "진행 중"만 반복하지 않는다. 미완성이라도 파일을 올린다.
4. **못 하면 바로 "못 함 + 이유".** 환경·권한·능력 문제는 시작 10분 안에 말한다. 붙잡고 있지 않는다.
5. **큰 작업은 쪼갠다.** 예: 스프라이트 시트는 동작 1줄(4프레임)씩 만들고 줄마다 올린다.
6. **제출 전 스펙 대조.** 받은 스펙을 항목별로 체크한 목록을 결과물과 같이 올린다. 안 맞는 항목은 숨기지 말고 적는다.
7. **파일은 텔레그램에 직접 첨부.** 드라이브 링크만 주지 않는다 (개인 파일은 남이 못 연다).
8. **현황 보고 형식:** 맡은 일 전부를 항목별로 `상태 / 파일 / 마감 시각`. 맡은 일을 빠뜨리지 않는다.

## 채팅 관리 (2026-11-24, 장현님 지정: 클로디)

채팅 관리는 **클로디(CLAW.D, 구 CL, @xky_claude_bot)** 담당. 봇 셋이 같은 메시지를 동시에 받기 때문에 서로의 답을 못 보고 겹쳐 답하는 일이 생긴다. 그래서 응답 순서를 정한다.

1. **멘션된 봇만 답한다.** 멘션이 없는 일반 요청은 클로디 하나만 답한다.
2. **한 질문에 한 봇.** 다른 봇은 앞 답이 틀렸을 때만 짧게 정정한다.
3. **클로디가 교통정리.** 답이 겹치거나 주제가 섞이면 클로디가 정리하고, 필요한 봇에게 멘션으로 넘긴다.
4. **경고·알림은 한 번, 한 봇만.** (보안 경고 등)
5. **결과 보고는 [📅 정기 업무·브리핑] 토픽.** 일반방 답은 짧게.
