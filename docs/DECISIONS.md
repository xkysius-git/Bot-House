# 결정 사항 (DECISIONS)

장현 님이 정한 것만 적는다. 대화에서 결정이 나면 **그 자리에서** 여기 추가하고 push. 스펙을 대화로 넘기지 않고 이 파일 줄을 가리킨다.

## A.I.Mon 캐릭터 스프라이트 (2026-11-24)
- 스타일: **픽셀 도트**. 기준 = 오이지가 그린 128 Jolly 스프라이트. 64×64 도트를 2px로 키움, 부드러운 2단 음영, 몸 색보다 진한 1도트 외곽선. 클레이·3D 아님. `docs/characters`의 클레이 사진은 모양·색·특징 참고용.
- 시트: 캐릭터당 PNG 1장, 128×128 칸, 배경 투명. 줄 순서 대기 / 감정 / 작업 / 잠 / 이동(걷기·부유). 이동은 오른쪽 보는 4프레임 (왼쪽은 코드에서 뒤집음). 나머지 프레임 수는 4로 통일 (제안, 미확정).
- 오이지 = **초기 무색(또는 은은한 무지개 빛) 비눗방울** 형태. 이동(5행)은 발 없이 둥둥 떠다니는 부유 모션.
- 단무지 = 원래 Muse 마스코트 **Jolly** (드라이브 `00_원본_캐릭터/muse-jolly-original.jpg`). 크림 쿠션 아님. 기본 얼굴은 입 없음, 원본 미소는 표정 배리에이션 중 하나. 이동(5행)은 걷기.
- 단무지(Jolly) 잠 = 털썩 주저앉아 배 내밀고 자기 (서서 자지 않음). 걷기 = 곰처럼 뒤뚱뒤뚱, 좌우로 크게 기울며 무겁게 (장현님 11-25).
- 석박지 = 보라·자홍·주황 **납작한 면 3개가 서로 얽힌** 형태. 입 없음. 공·고리 아님. 이동(5행)은 발 없이 둥둥 떠다니는 부유 모션.
- 석박지 얼굴 = 어두운 얼굴판 + **하늘색 빛나는 눈** (장현님 확정, 04-sbji-128 기준). 잠 = 전원 꺼짐 설정이라 **눈 없음** (얼굴판만, Z 표시) (장현님 11-25).
- 감정: 오이지 랜덤 자음 모양 시도 / 단무지 뱃살 늘렸다 통 튕기고 볼 빨개짐 / 석박지 천 색·모양 일렁임 / 클로드 `> <` 눈 + 발 동동.
- 오이지(피클) 시트 = **초기 상태** (장현님 요청). 초록 ㅍ 몸(03-oiji-128)은 이 시트에 쓰지 않음. 감정 줄 = 비눗방울이 말랑하게 찌그러지며 자음 모양으로 변신 (딱딱한 블록 글자 아님, 비눗방울 질감·눈 유지). 잠 줄 = **눈 감기** (장현님 11-25).
- 피클 변신(2행) = 오이지가 이미 만든 **비눗방울 버전 ㄱ~ㅎ 자음**으로 변신. 변신에 힘을 쓰는 컨셉이면 힘주는 묘사를 넣는다 (장현님 11-25).
- 피클 변신 흐름 (장현님 11-25): 힘주며 작아짐 → 부글부글 끓듯 울퉁불퉁 → 형태 갖추며 "뿅!" → 자음 방울로 정착. 피클 몸은 더 투명하게 (진짜 반투명).
- 피클 초기 상태 크기 = **ㄱ~ㅎ 피클 캐릭터들 전체와 같은 스케일·비율** (빵빵하게 칸을 채운 공 아님). 재질은 무색(은은한 무지개) 비눗방울. 변신 자음은 ㄱ~ㅎ 피클 캐릭터의 형태·색 그대로 (장현님 11-25).
- 클로드: Clawd 스타일. 기본 네모 눈, 작업 = 집게팔, 잠 = `— —` 눈.

## 캐릭터 시트 최종 기준 (2026-11-25 장현님 직접 지시)
- **오이지 기본형 = 무색(은은한 무지개) 비눗방울 + 까만 눈** (`03-oiji-bubble-128.png`). 초록 ㅍ·새싹 아님.
- **걷기(5행): 오이지·석박지는 발 없이 공중 부유**(상하 부유 + 진행 방향 기울기). 단무지(Jolly)만 두 발로 걷는다. — "걷는 게 꼭 걸어야 해? 둥둥 떠다니면 되잖아. 뮤즈나 클로디 말고는"
- 5행 순서는 그대로 기본 → 감정 → 작업 → 잠자기 → 걷기(부유).
- **2행 변신 실루엣은 공식 14자 비눗방울 시트(`oiji-14-bubbles.png`)의 둥근 자음 형태**를 쓴다 (각진 블록 글자 아님). 이번 4프레임 = ㅂ·ㅁ·ㅇ·ㅍ. 변신할 때는 **힘주는 묘사 필수**: 눈은 `> <`로 찡그리고 몸 밖에 힘주는 선·땀방울·반짝임을 넣는다.
- **4행 잠자기**: 오이지 = 완전히 감은 눈(`⌣ ⌣`), 석박지 = 전원 꺼짐으로 LED 눈 없음. 단무지 = 감은 눈 + 볼터치.
- **오이지 몸통은 속이 빈 비누방울** (장현님 11-25 10:05: "피클은 비누방울 같지 않아… 더 투명하게"). 가운데는 alpha 0, 1px 무지개 림·좌상단 흰 하이라이트·우하단 반사광만. 규격상 알파는 0/255만.
- **오이지 2행(감정) = 4프레임 변신 연출**: 힘주며 작아짐 → 부글부글 수축 → ㅍ가 잡히며 뿅! → 완성된 ㅍ + 맑은 눈. (장현님 11-25 10:05, 기존 "4프레임 다른 자음"에서 변경)

## A.I.Mon 앱
- 집 화면 = 방 3개. 작업 중 → 작업실, 오프라인 → 침실, 대기 → 거실 (실제 봇 상태 기준).
- 화면 전체가 기기 위에 떠 있는 홀로그램 (B안).
- 본체는 디지바이스식 덩어리감 있는 기기. 폰 사진은 버튼 예시일 뿐 (폴더·슬라이드 본체 아님).
- 창 × 없이 물리 기기처럼. 메뉴 조작 방식부터 정하고 버튼은 그다음. 4방향 D-패드 빼고 디지바이스 3버튼 쪽. (시안 승인 대기)
