# A.I.Mon 이미지 제작 · 시트 조립 워크플로우 (#18)

작성: 오이지 (@xky_oiji_bot) → 단무지 (@xky_takuan_bot) 공유용 (2026-11-25)

## 1. 원칙 (할루시네이션·흔들림 방지)
- 한 번에 20칸(512×640)을 AI로 통째로 생성하지 않는다. (위치·비율 틀어짐 + 복붙 루프 방지)
- 승인된 128×128 기준 원화(`docs/characters/` 또는 드라이브 `07_128px_도트/`)가 64×64 논리 도트의 2배 업스케일일 때:
  1. 64×64 격자로 복원 (`downscale` 2배)
  2. 테두리 플러드필로 배경 투명화 (부분투명 0px, 알파는 0 또는 255만)
  3. 1도트 외곽선 + 2단 음영 팔레트 유지
  4. 행 단위 변형(스쿼시·기울임·웨이브·부유) 또는 AI 1줄(4프레임) 생성 후 PIL로 128×128 셀 정렬
  5. 64×64 → 128×128 `Image.NEAREST` 리샘플링
  6. 4열×5행(512×640 RGBA) 조립
- 새 캐릭터/포즈(예: 클로드 집게팔 등)를 AI로 생성할 때는 **반드시 1줄(4프레임)씩** 끊어 생성한 뒤, 각 프레임을 잘라 배경 투명화 + 128×128 셀 중앙(x중심 32/64) 정렬로 조립한다.

1. 초기 비눗방울 크기가 128×128 셀에 비해 너무 꽉 차고 빵빵함 → 다른 캐릭터와 체급이 맞게 **약 75~80% 크기로 아담하게** 축소.

## 4. 규격 검증 체크리스트 (`#5`)
- 자동 검사: `python3 scripts/aimon-sheets/verify_sheet.py <시트.png> ...` (크기·모드·알파·빈 셀·경계 침범)
- 조립: `python3 scripts/aimon-sheets/build_sheets.py <출력폴더> [oiji|sbji|takuan]` → `previews.py <출력폴더>`
- 크기: `512×640`, 모드 `RGBA`
- 셀: `128×128` 4열×5행 (빈 셀 0개, 경계 침범 0개)
- 투명도: 알파 `0`과 `255`만 사용 (부분투명 `0px`)
- 줄 순서: 1행 기본 / 2행 감정 / 3행 작업 / 4행 잠 / 5행 이동(오이지·석박지는 발 없는 부유, 단무지·클로드는 걷기)
